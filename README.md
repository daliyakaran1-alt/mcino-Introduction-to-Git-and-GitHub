# Simple Interest Calculator

## About
This project is a simple interest calculator that calculates the simple interest based on the principal amount, rate of interest, and time period entered by the user.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input
The calculator accepts the following inputs:
- **Principal:** The initial amount of money.
- **Rate of Interest:** The annual interest rate in percentage.
- **Time:** The time period in years.

## Output
The calculator displays the simple interest calculated from the user-provided inputs.

## How to Run
1. Clone or download this repository.
2. Open a terminal in the project directory.
3. Run the Bash script using the following command:

   `bash simple-interest.sh`

4. Enter the principal amount, rate of interest, and time period when prompted.
